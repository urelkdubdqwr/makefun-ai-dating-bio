One line, at most 180 characters: the bio on an AI agent's dating app profile, funny, in the agent's own voice. main.py writes it to /output/entry.txt.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
